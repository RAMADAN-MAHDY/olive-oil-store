


          
# وصف مشروع متجر زيت الزيتون الطبيعي

هذا المشروع هو تطبيق ويب لمتجر "زيت الذهب الأخضر"، وهو متجر متخصص في بيع زيت الزيتون الطبيعي عالي الجودة. التطبيق يتكون من واجهة أمامية (Frontend) وواجهة خلفية (Backend) لتوفير تجربة مستخدم متكاملة لإدارة الطلبات، عرض المنتجات، التقييمات، والمميزات.

## المكونات الرئيسية للواجهة الأمامية (olive-frontend)
- **index.html**: الصفحة الرئيسية للموقع تحتوي على أقسام متعددة مثل الرئيسية، المميزات، المنتج، آراء العملاء، وقسم الطلبات.
- **admin.html**: لوحة تحكم الأدمن لإدارة إعدادات المنتج والطلبات.
- **js/**: مجلد يحتوي على ملفات جافاسكريبت التي تدير منطق الموقع، مثل:
  - `apiConfig.js`: إعداد رابط الـ API المركزي.
  - `reviewModal.js`: منطق مودال إضافة التقييمات.
  - `reviews.js`: جلب وعرض آراء العملاء.
  - `order.js`: منطق الطلبات (إرسال الطلب، متابعة الطلبات).
  - `productSettings.js` و `adminProductSettings.js`: إدارة إعدادات المنتج.
  - `auth.js`: منطق تسجيل الدخول والتوثيق.
  - `navbar.js` و `timeline.js`: إدارة شريط التنقل والانتقال بين أقسام الصفحة.

## المميزات والوظائف
- تصميم متجاوب يدعم اللغة العربية مع اتجاه من اليمين إلى اليسار.
- نظام تقييم العملاء مع إمكانية إضافة تقييمات جديدة.
- نموذج طلب متكامل مع خيارات الكمية والأسعار والخصومات.
- لوحة تحكم للأدمن لإدارة إعدادات المنتج والطلبات.
- شريط تنقل جانبي (تايم لاين) للتنقل السريع بين أقسام الموقع.
- استخدام تقنيات حديثة مثل Tailwind CSS لتصميم الواجهة.
